# AWS Architecture Icons

Unmodified SVGs from the official AWS Architecture Icons package, release 07312026
(https://aws.amazon.com/architecture/icons/). Service icons are the 64 px set; the AWS Cloud and Auto
Scaling group icons come from the group icon set. Do not recolour, crop or restyle them. They appear only in
architecture diagrams and the decorative hero graphic (`HeroArchitecture.astro`), and do not
imply endorsement by AWS.

The generic Users and Email icons (`users-*.svg`, `email-*.svg`) are from the General Resource icon
set (`Res_Users_48_Light/Dark`, `Res_Email_48_Light/Dark`); the Light file is for the light theme,
the Dark file for the dark theme.
