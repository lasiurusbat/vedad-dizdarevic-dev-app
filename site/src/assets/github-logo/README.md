# GitHub logo

Unmodified Invertocat SVGs (black and white) from GitHub's official logo package
(https://brand.github.com/GitHub_Logos.zip, linked from https://github.com/logos). Used only in the
architecture diagram to mark GitHub Actions and the git tag in the release path. Do not recolour,
rearrange or restyle them, and keep them on a high-contrast background. Black shows in the light
theme, white in the dark theme.
